# АнатЭкзам

Тренажёр по анатомии для подготовки к экзамену: карточки Сапина, латинские термины, тесты, оси и движения суставов.

Сайт: https://mihamed24.github.io/anatexam/

## Структура

- `index.html` — каркас страницы и подключение скриптов
- `css/style.css` — оформление
- `js/app.js` — код приложения: экраны, режимы игры, прогресс, статистика
- `data/content.js` — каркас данных `CONTENT`
- `data/sections/*.js` — разделы: темы, термины, справочные статьи, точки на карточках
- `data/base.js`, `data/crops.js` — «База латыни» и вырезки карточек
- `data/images.js` — соответствие id картинки файлу в `img/`
- `img/` — карточки Сапина (webp)

Порядок подключения файлов задан в `index.html`: данные идут раньше `js/app.js`.

## Локальный запуск

Достаточно открыть `index.html` в браузере, сервер не нужен.
